# inochi_web Python Server Example

This example hosts the `inochi_web` WASM viewer from a dedicated folder and serves it with a Python stdlib HTTP server.

## Structure

- `server.py`: local HTTP server entrypoint.
- `app/index.html`: viewer page.
- `app/viewer.js`: UI logic and interaction controls.
- `app/style.css`: styling.
- `app/assets/Aka.inp`: bundled sample model.
- `app/pkg/`: generated by `wasm-pack` (ignored in git).

## Build the WASM package

From the `inochi_web/` directory:

```bash
wasm-pack build --target web --out-dir examples/python-server/app/pkg
```

Expected result: `examples/python-server/app/pkg` contains `inochi_viewer.js`, `inochi_viewer_bg.wasm`, and related files.

## Run the example server

From the `inochi_web/` directory:

```bash
python examples/python-server/server.py
```

Then open:

```text
http://127.0.0.1:8080
```

## Usage

1. Build WASM as described above.
2. Start the server.
3. Open the URL in your browser.
4. Load a `.inp` or `.inx` file using the file picker.

Important: do not open `app/index.html` with `file://`; use HTTP server mode.

## Notes

- The server root is fixed to `examples/python-server/app`.
- `.wasm` is explicitly served as `application/wasm`.
- Host and port defaults are `127.0.0.1:8080`.
