Beginner-first documentation for this project lives in:

- [`docs/README.md`](docs/README.md)

## Quick Context

- This repository is intended to be the root project.
- `inox2d/` is a required modified fork used by this implementation.
- Clone with submodules so you get the correct fork state from day one.

```bash
git clone --recursive https://github.com/emanuel-mena/Inochi2DWebAvatarFramework.git
```

If you already cloned without recursion:

```bash
git submodule update --init --recursive
```

For full onboarding (Windows, macOS, Linux), start at [`docs/README.md`](docs/README.md).
